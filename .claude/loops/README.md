# Loop prompts

Copy-paste prompts for `/goal`, `/loop` and Ralph. Each one states a measurable end, a turn or
iteration cap, and the skill that proves success. Rule of thumb: timer outside, condition inside,
skill innermost.

| File | Use |
|---|---|
| `goal-slice.md` | Finish one plan slice end to end (supervised or auto mode) |
| `goal-golden-gate.md` | Iterate on one model until its gate group passes or the budget is spent |
| `goal-drawing-stage.md` | Work the drawing recognition slices (S6a–S6e, KAN-38), one per iteration |
| `loop-ci-babysitter.md` | Every 15 minutes: keep my PRs green and answered |
| `loop-canary-watch.md` | Every 5 minutes: watch a staging canary, recommend promote or roll back |
| `ralph-overnight.md` | Overnight: work through ready slices, one PR each, stop when empty |
