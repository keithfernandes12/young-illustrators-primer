# docs/meeting-notes

What a meeting decided, and who owns each action.

- Start from `_template.md`. File name starts with the date: `2026-10-25-weekly-sync.md`.
  `type: meeting-note`; `status: draft` → `final`.
- Decisions and action items only, each action with an owner and a Jira key where one exists.
  Not a transcript.
- A decision that others must follow also gets an ADR; link it in `related`.
