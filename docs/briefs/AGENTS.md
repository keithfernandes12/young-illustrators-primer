# docs/briefs

A brief shapes something not yet decided: a vague idea or a Jira epic turned into the problem,
options, open questions and candidate slices, so the team can decide.

- Start from `_template.md` (the `shape-feature` skill fills it). `type: brief`; `status: draft` →
  `decided` (link the ADR or plan it became in `related`) or `parked`.
- List what you read, what you did not read, and what you assumed.
- One question per open item, each with a recommended answer.
