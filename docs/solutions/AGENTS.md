# docs/solutions

A solution records a problem we solved that is likely to come back, so the next person recognises
it in minutes instead of hours.

- Start from `_template.md`. `type: solution`; `status: active` or `deprecated`.
- Sections: symptom (exact error text, so it can be searched), cause, fix, how to tell it is this
  problem and not another.
- Agents check this folder before debugging (see `docs/engineering/engineering-loop.md`).
